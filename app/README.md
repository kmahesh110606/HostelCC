# HostelCC Flutter App

## Run
1. Install Flutter SDK
2. If this is your first time in this folder, generate platform folders:
   - `flutter create .`
3. From this folder:
   - `flutter pub get`
   - `flutter run`

## API Base URL
Update `apiBaseUrl` in `lib/main.dart` according to your device:
- Android emulator: `http://10.0.2.2:8080`
- iOS simulator / web: `http://localhost:8080`
